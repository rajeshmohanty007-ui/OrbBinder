# Start Scene
- start button
- leaderboard button
- reasume button 
- characters button 
- settings button

# Initial game scene 
- character sprite
- ground container
- background container
- camera follows hero
- left, right movement
- cam shot on reaching the enemy
- launching beam scene
- removing previous tiles and rendering further tiles
- small chalenges to reach the next enemy
- camshot on next enemy.
- launching beam scene again. Then the cycle repeats.

# Beam scene
- pause the player movement
- beam menu appears
- player chooses the beam parts
- time limited 15 sec.
- player performs the attack
- damage is counted
- If the enemy doesn't die it attacks the player. Enemy react scene launches.
- the beam scene is stopped.
